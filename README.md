# 🍽️ Restaurante "El Gran Banquete"

> "Sabores auténticos de la cocina tradicional con un toque moderno y digital".  

Este proyecto es la plataforma web oficial de **El Gran Banquete**, diseñada para ofrecer una experiencia digital fluida, permitir reservas en línea, mostrar nuestro menú actualizado y conectar con nuestros clientes.

---

## 🚀 Características Principales

*   **Menú Digital Interactivo:** Explora platillos por categorías con filtros en tiempo real.
*   **Sistema de Reservas:** Formulario intuitivo para asegurar tu mesa en segundos.
*   **Desplazamiento Suave (*Smooth Scroll*):** Navegación fluida entre secciones para mejorar la experiencia de usuario.
*   **Diseño 100% Responsivo:** Optimizado para computadoras, tabletas y teléfonos móviles.
*   **Localización e Contacto:** Integración con mapas y enlaces directos a redes sociales.

---

## 🛠️ Tecnologías Utilizadas

*   **HTML5:** Estructura semántica del sitio web.
*   **CSS3:** Estilos personalizados, Flexbox, Grid y efectos de transición visual.
*   **JavaScript:** Interactividad del menú, validación del formulario de reserva y animaciones.
*   **BootStrap:** Maquetación y estilizado de forma rápida

---

## ⚙️ Instalación y Uso Local

Sigue estos pasos para ejecutar el proyecto en tu entorno local:

1. **Clona este repositorio:**
   ```bash
   git clone "link de github que no pongo para que no lo clone cualquiera"
   ```

2. **Navega al directorio del proyecto:**
   ```bash
   cd tu-repositorio
   ```

3. **Abre el archivo principal:**
   Simplemente haz doble clic en el archivo `index.html` o utiliza la extensión *Live Server* en Visual Studio Code.
